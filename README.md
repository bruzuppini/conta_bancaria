# Projeto Conta Bancária

Projeto backend que simula funcionalidades de um sistema de conta bancária utilizando TypeScript e Node.js. Foi desenvolvido com foco em lógica orientada a objetos para representar operações bancárias como saque, depósito e consulta de saldo, e demonstra o uso de classes e tipos do TypeScript para estruturar regras de negócio e organizar funcionalidades.
Principais tecnologias: TypeScript, Node.js, lógica de programação orientada a objetos.
